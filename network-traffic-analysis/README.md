# Network Traffic Analysis (Wireshark) – Simulated

## Scenario
Suspicious network traffic was identified during routine monitoring, requiring packet-level analysis to determine potential malicious activity.

## Analysis Steps
- Captured and reviewed network packets
- Analyzed source and destination IP addresses
- Identified abnormal protocols and ports
- Inspected DNS and HTTP traffic for suspicious patterns
- Evaluated traffic behavior for potential data exfiltration

## Tools Used
- Wireshark

## Findings
- Suspicious outbound connections identified
- Abnormal DNS queries observed
- No confirmed data exfiltration detected

## Response Actions
- Traffic flagged for further monitoring
- Findings documented and escalated for review
- Network security controls reviewed

## SOC Relevance
- Supports threat detection and incident investigation
- Enhances visibility into network-based attacks
